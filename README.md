# My Personal Portfolio

This is a multi-page personal portfolio website created for the Thiranex HTML5 Semantic Structure and Accessibility task.

## About the Project

The portfolio presents my introduction, education, skills, projects and contact information using semantic HTML5 structure and accessibility practices.

## Pages

- Home
- About
- Projects
- Contact

## Features

- Semantic HTML5 elements
- Accessible navigation
- ARIA labels and attributes
- Keyboard-friendly contact form
- Proper form labels
- SEO-friendly meta tags
- Responsive design
- Visible keyboard focus indicators
- Descriptive page titles

## Technologies Used

- HTML5
- CSS3

## Semantic HTML5 Elements Used

- header
- nav
- main
- section
- article
- footer

## Accessibility

The website includes proper labels for form fields, ARIA navigation labels, required form validation and visible focus indicators to improve keyboard and screen-reader accessibility.

## SEO

Each page includes:

- Title tag
- Meta description
- Meta keywords
- Author information
- Responsive viewport meta tag
